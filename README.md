# Pawprint Planet: Miso’s Cast Lab

A browser based learning game for elementary learners, built with HTML, CSS, and JavaScript. It starts fresh on each visit and uses no login or student account.

## Play

Open `index.html` in a modern browser. Create a helper avatar, then guide Miso through one focused case: notice her limp, inspect a simplified simulated X-ray, and open all five treatment and care cards. A five-question mini quiz checks the learner's understanding of each option's purpose and where it best applies; missed questions include feedback and can be retried. Only after completing the quiz can the learner choose a plan. Then they trace a winding guide on Miso’s model foreleg to apply three simulated layers: stockinette sleeve, cast padding, and a fiberglass cast shell. A completed case note can be saved to the in-game case book for the current session.

The cast interaction is deliberately a simplified visual simulation. It does not teach limb positioning, application pressure, fit, or real casting technique and is not medical or veterinary instruction. A real veterinarian assesses each fracture and chooses treatment; children should tell a grown-up if an animal is hurt.

The treatment facts are based on the [MSD Veterinary Manual’s cat fracture overview](https://www.msdvetmanual.com/cat-owners/bone-joint-and-muscle-disorders-of-cats/bone-disorders-in-cats) and its [professional overview of fractures in dogs and cats](https://www.msdvetmanual.com/musculoskeletal-system/osteopathies-in-small-animals/bone-fractures-in-dogs-and-cats). The two-view radiograph concept follows veterinary guidance on orthogonal views for evaluating fractures ([feline fracture review](https://pmc.ncbi.nlm.nih.gov/articles/PMC11107983/)). The cast model uses common cast materials such as stockinette and padding ([small-animal casting techniques](https://www.ivis.org/library/current-techniques-small-animal-surgery-5th-edition/commonly-used-splinting-and-casting-techniques)). The display fonts load from Google Fonts when the device is online. The game content and interactions are local files.
